# JavaScript-Exercise

一个纯前端的 JavaScript 学习与练习网页，包含：

1. **知识库**：现已包含 **知识总览页 + 32 个独立知识页 + 3 个扩展工具页**，按 **知识大类别 / 知识点 / 基础内容 / 进阶与趣味内容** 组织，方便继续扩充成更完整的教程站结构。
2. **题库**：按 **难度 + 题型** 拆分为独立页面，包含选择题、填空题、实战题，并补充了更多覆盖面更广的题目。
3. **挑战项目**：在首页与实战题页增加挑战项目入口，帮助把多个知识点串成完整页面功能。
4. **实战编辑器**：在实战题页面中可直接修改示例代码并预览结果。

## 使用方式

直接在浏览器打开以下文件即可：

- `./index.html`

## 内容说明

- 知识库：1 个总览页 + 32 个独立知识页 + 3 个扩展工具页，按 6 个知识大类别组织
- 题库：147 题（选择 57 + 填空 48 + 实战 42）
- 首页提供学习节奏说明、知识库与题库导航、挑战项目入口
- 页面内参考了主流权威资料体系（见页面底部“参考资料”）
