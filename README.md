# JavaScript-Exercise

一个纯前端的 JavaScript 学习与练习网页，包含：

1. **知识库**：按 **基础 / 进阶 / 困难** 分页整理的知识路线，内容更适合从零开始的学习者逐步阅读。  
2. **题库**：按 **难度 + 题型** 拆分为独立页面，包含选择题、填空题、实战题，并对原题重新分类后补充了更多题目。  
3. **实战编辑器**：在实战题页面中可直接修改示例代码并预览结果。

## 使用方式

直接在浏览器打开以下文件即可：

- `./index.html`

## 内容说明

- 知识库：18 个主题，按难度拆分页面
- 题库：125 题（选择 48 + 填空 39 + 实战 36）
- 首页提供知识库与题库导航，方便按难度 / 题型跳转
- 页面内参考了主流权威资料体系（见页面底部“参考资料”）
