# JavaScript-Exercise

一个纯前端的 JS 练习网页，包含：

1. **知识库**：基础到进阶知识点讲解，带代码示例和可运行预览。  
2. **题库**：共 **100 题**（选择题、填空题、实战题）。  
3. **实战编辑器**：可直接在页面中写代码并实时预览效果。

## 使用方式

直接在浏览器打开以下文件即可：

- `/home/runner/work/JavaScript-Exercise/JavaScript-Exercise/index.html`

## 内容说明

- 题目总量：100（选择 40 + 填空 30 + 实战 30）
- 知识库与题目设计参考了主流权威资料体系（见页面内“参考资料”）
